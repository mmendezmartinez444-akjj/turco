# Capturas

Guardar aquí las capturas **reales** de la app corriendo en un emulador o teléfono Android
(no maquetas). Nombres sugeridos:

| Archivo | Qué mostrar |
|---|---|
| `01_agenda.png` | Agenda (pantalla inicial) con turnos del día |
| `02_agenda_oscuro.png` | Agenda en modo oscuro |
| `03_detalle_turno.png` | Detalle de un turno programado |
| `04_formulario_turno.png` | Formulario de turno (cliente, servicios, estilista) |
| `05_formulario_errores.png` | Formulario con errores de validación visibles (pulsar *Guardar turno* vacío) |
| `06_franjas_deshabilitadas.png` | Cuadrícula de franjas con horas deshabilitadas (elegir un estilista con turnos ese día) |
| `07_clientes.png` | Clientes |
| `08_servicios.png` | Servicios |
| `09_estilistas.png` | Estilistas |
